# Soda Container Taste Analysis

Does drinking soda from a glass bottle, aluminum can, or plastic cup affect how crisp it tastes?

This project uses a randomized complete block design to investigate whether container type influences perceived soda taste. The analysis was conducted in R using ANOVA, model diagnostics, and post-hoc comparisons and documented using Quarto.

Technologies: R • Quarto • ANOVA • Experimental Design • Data Visualization
